值得关注的 AI 新项目

近期研究（非过去 24 小时新增）：E2B Workload Identity

问题与更新：E2B 11 月 3 日发布说明：为每个沙箱执行提供带受众和有效期的签名 JWT，在沙箱外出站代理注入请求头。相较多个任务共用固定 API key，可让后端识别请求对应的项目、沙箱和执行；权限仍由业务系统决定。

场景与成熟度：车企内部智能体执行文档处理或工具调用时，后端可核对任务身份再授权读取。官方称 E2B Cloud 正式可用，BYOC 需支持团队启用；本次未独立实测或找到车企案例。

部署与边界：托管云或 BYOC，需 E2B SDK、允许出站的 HTTPS 服务及后端 JWT 验证；须校验签名、发行方、受众、过期时间、任务与沙箱映射，并独立配置数据权限和日志。出站代理、数据驻留与网络限制要核实；并非完全离线方案。

成本与许可：商业服务，沙箱及网络费用、BYOC 价格与具体 SDK 许可待确认。

试点：值得隔离试点。用 2 个测试任务和 100 次请求测试身份匹配、过期与错误受众拒绝；目标越权成功 0 次，另统计 P95 延迟、每任务费用和异常恢复时间。

近期研究（非过去 24 小时新增）：Cohere Model Vault 开放模型托管

问题与更新：11 月 3 日官方发布记录称 Model Vault 可在专用托管基础设施部署第三方开放模型，支持 OpenAI 兼容接口；标准版提供美国、欧盟和加拿大区域，加密版当时在美国可用，其他区域计划中。与自建 GPU 相比减少基础设施运维，但要核验区域与服务边界。

适用与成熟度：可作为海外车主服务知识问答的模型部署候选；官方称已可在产品中使用，本次未独立试用或核实车企案例。托管服务，不等同于车企私有机房部署。

部署、数据与成本：通过 Vault endpoint 和 API 密钥接入；厂商称默认不保留提示词及回复，加密版有额外机密计算保护，仍需审核合同、审计与数据驻留。按 GPU 小时计价，具体规格、最短租用、模型许可证和费用待确认。

试点：在确认区域和商业条款后，用 200 条脱敏中英双语服务问题与现有托管或自建模型比较正确率、P95、每千问总成本及跨境数据路径；没有中文效果证据前不安排生产替换。
