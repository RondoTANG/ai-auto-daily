LiveKit Agents 1.8.11：实时语音与车主服务

日期与证据：官方版本页显示 11 月 5 日发布，时区待确认。版本新增通过 LiveKit Inference 使用 Responses API，新增语音识别和语音合成供应商，并调整轮次检测及不可打断语音时的转录保留。官方 release

产品价值（分析）：框架连接 STT、模型、TTS 与电话系统，适合用作预约保养、售后进度查询的语音服务原型；不同于单独的语音识别接口，它还处理实时对话与轮次。新的供应商接入不代表中文表现或车企效果已经验证。

成熟度、部署和边界：公开仓库含示例和正式版，未独立运行，车企生产案例待确认。Python Agent 服务可自建，需 LiveKit Server 或云端服务，以及所选识别、模型和合成服务；部分新供应商要求 Python 3.11 以上。语音、转录和工具参数可能流向外部服务，需确认数据留存、区域及客户授权。仓库与示例

成本与许可：框架 Apache 2.0；轮次检测模型使用独立的 LiveKit Model License，需另行核对；计算、电话及模型服务费用按实际供应商计费，具体价格待确认。

试点建议：值得开展隔离测试。以 100 条脱敏预约及查询对话覆盖方言、插话和转人工，统计识别错误率、用户打断成功率、首字延时 P95、人工接管后上下文保留率和每通成本；与现有 IVR 在同一录音集上比较。涉及订单修改时须增加身份验证与人工确认。

产品优先级

优先建立语音客服评测集和转人工链路，再决定是否替换现有语音组件：近期版本扩大了供应商选择，但中文效果、实时性和单位成本仍须以同一数据集实测。
