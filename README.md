# AI 与汽车 AI 趋势日报

这是独立的公开日报项目。首页为最新一期日报，历史期次保存在 issues/。

## 内容

覆盖通用 AI 与汽车 AI。通用方向关注模型、多模态、产品、智能体、知识库、企业工具及部署与成本变化；汽车方向关注智能客服、外呼、知识库、AI 中台、售前售后、车主与经销商服务，以及座舱、智驾和研发制造的重要 AI 应用。

每项应注明事件和报道日期、来源、影响与跟踪指标，区分事实、厂商宣称和分析。新项目注明成熟度、部署、成本、许可证和试点方向。按价值筛选，不凑条数；无新增时如实说明。

## 发布

使用 GitHub Pages，从 main 分支根目录发布静态页面。日报自动任务负责检索、撰写和更新，不要新建定时任务。

每次更新前读取 README、当前首页和历史期次去重。更新 index.html，创建 issues/YYYY-MM-DD.html 快照并保留所有历史期次。首页与历史页的链接使用相对于当前页面的路径，以支持 GitHub Pages 项目子路径。页面保持响应式，来源使用真实 HTTPS 链接。

仅提交公开资料编写的内容与静态代码，不放入凭据或非公开信息，也不自动公开迁移原私有站内容。发布前检查链接、日期与移动端样式；提交后检查 Pages 部署结果，成功后才返回真实网页地址。部署失败则说明并提供精简备份。
